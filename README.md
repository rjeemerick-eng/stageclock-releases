# StageClock — Releases

Download the latest **StageClock** for macOS and Windows from the
[Releases page](https://github.com/rjeemerick-eng/stageclock-releases/releases/latest).

- **macOS:** download the `.dmg` (Apple-notarized — no Gatekeeper warnings)
- **Windows:** download `StageClock-Setup-x.y.z.exe`

The app updates itself automatically after installation.

This repository hosts release binaries only. StageClock is a production
timer and rundown system for live events — operator console, networked
stage displays, per-display views, MIDI/OSC control, and NDI output.
